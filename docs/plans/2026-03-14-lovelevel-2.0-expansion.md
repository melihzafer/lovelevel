# LoveLevel 2.0 - Feature Expansion Plan

## Vision
Transform LoveLevel from a pet companion app into the **ultimate relationship app** - combining pet care, couple activities, communication, and memory-keeping in one delightful experience.

---

## Phase 6: Real-Time Communication (Week 1-2)

### 6.1 Couple Chat System
- **Real-time messaging** between partners using Supabase Realtime
- **Message types**: Text, emojis, voice notes, love notes
- **Message reactions**: React with hearts, kisses, hugs
- **Typing indicators**: See when partner is typing
- **Read receipts**: Know when messages are read
- **Chat themes**: Customize chat appearance

### 6.2 Love Notes
- **Scheduled love notes**: Write notes that appear at specific times
- **Surprise notes**: Random pop-up love notes on partner's screen
- **Note templates**: Pre-written romantic messages
- **Animated delivery**: Notes appear with heart animations

### 6.3 Voice Messages
- **Record voice notes** (up to 60 seconds)
- **Voice-to-text transcription**
- **Play directly in chat**
- **Voice message reactions**

---

## Phase 7: Shared Activities & Games (Week 2-3)

### 7.1 Multiplayer Couple Games
- **Truth or Dare**: Couple edition with romantic/fun prompts
- **Would You Rather**: Relationship-themed questions
- **Two-Player Trivia**: Compete or cooperate
- **Drawing Together**: Collaborative drawing canvas
- **Song Guessing**: Guess songs together
- **Memory Duel**: Compete in memory matching

### 7.2 Shared Pet Activities
- **Feed together**: Both partners must tap to feed pet
- **Pet walks**: Go on virtual walks together
- **Pet photos**: Take photos of pet together
- **Pet tricks**: Teach pet new tricks cooperatively
- **Pet bonding**: Activities that increase pet's love for both partners

### 7.3 Date Night Generator
- **AI-powered date suggestions** based on:
  - Weather conditions
  - Budget level
  - Time available
  - Location (home/outdoors)
  - Mood
- **Date history**: Track completed dates
- **Date ratings**: Rate and review dates
- **Date planning**: Schedule future dates

## Phase 8: Memory & Journal System (Week 3-4)

### 8.1 Couple Journal
- **Shared diary**: Both partners can write entries
- **Photo entries**: Add photos to journal entries
- **Mood tracking**: Track daily moods
- **Gratitude log**: Things you're grateful for
- **Prompts**: Daily journaling prompts for couples
- **Private entries**: Option for private thoughts
- **Anniversary entries**: Special entries for milestones

### 8.2 Memory Timeline
- **Visual timeline** of relationship milestones
- **Photo albums**: Organize photos by events
- **First times tracker**: First date, first kiss, first trip, etc.
- **Milestone celebrations**: Auto-detect and celebrate milestones

### 8.3 Photo Sharing

- **Photo reactions**: Partner can react to photos
- **Photo captions**: Add sweet captions
- **Photo filters**: Romantic filters for couple photos
- **Photo challenges**: Weekly photo challenges

## Phase 9: Pet Evolution & Customization (Week 4-5)

### 9.1 Pet Evolution System
- **Growth stages**: Baby → Child → Teen → Adult → Elder
- **Evolution triggers**: Based on care quality, time, and love
- **Visual changes**: Pet appearance changes with evolution
- **Personality development**: Pet develops personality traits
- **Special evolutions**: Holiday/seasonal variants

### 9.2 Pet Breeding
- **Partner's pets can meet**: When both are online
- **Pet playdates**: Schedule playdates between pets
- **Pet babies**: Breed pets to create new pets
- **Inherited traits**: Babies inherit traits from parents
- **Pet family tree**: Track pet lineage

### 9.3 Advanced Pet Features
- **Pet moods expanded**: More mood states and expressions
- **Pet sounds**: Pet makes cute sounds
- **Pet animations**: More idle animations
- **Pet dreams**: See what pet dreams about
- **Pet diary**: Pet writes about its day
- **Pet friends**: Pet can have friends (other pets)

## Technical Architecture Updates

### Backend (Supabase)
- **Realtime channels** for chat and multiplayer games
- **Row Level Security** for private data
- **Edge Functions** for AI features
- **Storage buckets** for photos and voice messages
- **PostgreSQL extensions** for advanced queries

### Frontend
- **React Query** for data fetching
- **Zustand** for state management (already using)
- **Framer Motion** for animations (already using)
- **WebRTC** for voice messages
- **Service Workers** for offline support (already have)

### New Dependencies
- `@supabase/realtime-js` - Real-time subscriptions
- `@tanstack/react-query` - Data fetching
- `wavesurfer.js` - Audio visualization
- `fabric.js` - Drawing canvas
- `date-fns` - Date utilities (already have)
